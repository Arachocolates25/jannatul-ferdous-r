# Rayhan Gazi — Personal Portfolio

Personal portfolio website for Rayhan Gazi (Khulna, Bangladesh).
Founder of Ara Chocolates · Web creator · Video editor and colour grader.

This version is deployed exactly from the files Rayhan uploaded on 2026-11-08.
Previous versions in this repo were replaced.

Design: sage #edf1e4, cocoa #2b1810, berry #c72c63, fonts Bricolage Grotesque + Newsreader.
Sections: Hero, About, Work (Ara Chocolates / Websites / Video and colour), Skills, Contact.

## Run locally
Open `index.html` in a browser, or: `python3 -m http.server`

## Live site (GitHub Pages)
https://Arachocolates25.github.io/rayhan-new-website/
Enable in Settings → Pages → Deploy from branch → `main` → `/ (root)`.
