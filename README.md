# Rayhan — Personal Portfolio

Super-fancy personal portfolio website for Rayhan (Khulna, Bangladesh).

Co-Founder of Ara Chocolates · Web Creator · Video Editor & Colour Grader

## What's inside — 7 zones
1. **Header & Navigation** — sticky, logo `R`, Home / About / Ventures / Skills / Gallery / Contact, Dark/Light mode switcher
2. **Hero** — big name, typing animation (Young Entrepreneur / Tech Enthusiast / Visual Creator), Explore My Work + Contact Me buttons, glowing profile frame
3. **About** — My Story + Quick Info cards (Khulna, Bangladesh; ICT, Web & Business)
4. **Ventures** — Ara Chocolates (Co-Founder), Tech & Web Projects, Video & Colour Grading
5. **Skills** — HTML & Web Design, Video Editing, Colour Grading, Brand Strategy + interests: Astrophysics, History & Geography, Automotive Engineering, Literature
6. **Gallery & Thoughts** — auto-playing photo slider + 3 short articles with Read More
7. **Contact & Footer** — message form, Instagram / Facebook / GitHub / Email buttons, © 2026 Rayhan

## Design
Deep navy blue / dark black background, white text, sky blue + gold accents. Hover lift + glow on cards and buttons. Fully responsive, dark/light themes.

## Run locally
Open `index.html` in a browser, or serve it:
```bash
python3 -m http.server
```

## Deploy with GitHub Pages
Settings → Pages → Deploy from branch → `main` → `/ (root)`. The site will be live at `https://Arachocolates25.github.io/rayhan-portfolio/`
